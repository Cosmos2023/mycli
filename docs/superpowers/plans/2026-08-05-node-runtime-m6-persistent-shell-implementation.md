# Node Runtime M6 Persistent Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Execution constraint:** The user has explicitly prohibited subagents. Execute this plan inline with
> `superpowers:executing-plans`; do not dispatch tasks. Obtain user confirmation before every commit
> and never push.

**Goal:** Make the Node backend complete a secure, recoverable, cross-platform persistent Shell turn
without starting Python.

**Architecture:** Add a backend-owned `ShellSessionManager` below transport-neutral tool adapters.
Pipe and `node-pty` transports feed one bounded lifecycle contract into storage, gateway, and the
existing TUI. Shell exposure remains disabled until command approval and platform sandbox gates are
wired and verified.

**Tech Stack:** TypeScript 5.9, Node 22.19/24, `node:child_process`, `node-pty@1.2.0-beta.15`, AJV,
better-sqlite3, Node test runner, Python 3.13 parity fixtures, npm workspaces.

**Design:** `docs/superpowers/specs/2026-08-05-node-runtime-m6-persistent-shell-design.md`

- [ ] **Step 4: Implement process-tree control and pipe launch**

one exit after both streams drain.

```ts
const child = spawn(request.executable, [...request.args], {
	cwd: request.cwd,
	env: { ...request.env },
	detached: request.platform !== "win32",
	shell: false,
	stdio: ["ignore", "pipe", "pipe"],
});
let sequence = 0;
child.stdout.on("data", (data: Buffer) => publish({ stream: "stdout", data, sequence: sequence += 1 }));
child.stderr.on("data", (data: Buffer) => publish({ stream: "stderr", data, sequence: sequence += 1 }));
```
