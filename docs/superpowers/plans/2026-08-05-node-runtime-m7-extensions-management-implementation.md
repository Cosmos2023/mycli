# Node Runtime M7 Extensions And Management Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Execution constraint:** The user has explicitly prohibited subagents. Execute this plan inline
> with `superpowers:executing-plans`; do not dispatch tasks. Before every commit, present the exact
> commit message and file list and wait for `ok`. Never amend or push.

**Goal:** Port every remaining M7 production capability to the compiled Node runtime so M8 can
retire Python without redesigning providers, extensions, subagents, setup, or diagnostics.

**Architecture:** Add Anthropic to the existing provider-neutral stream and create one
`@mycli/integrations` package for skills, MCP, hooks, Plugin API v2, and subagent control. Keep
`@cosmos2023/app` as the composition/management root and inject neutral extension contracts into
`@mycli/runtime`, preventing a runtime-integrations dependency cycle.

**Tech Stack:** TypeScript 5.9, Node 22.19/24, npm workspaces, `@anthropic-ai/sdk@0.115.0`,
`@modelcontextprotocol/sdk@1.30.0`, Ajv Draft 2020-12, `yaml@2.9.0`, smol-toml, better-sqlite3,
Node test runner, Python 3.13 parity fixtures, compiled ESM child processes.

**Design:** `docs/superpowers/specs/2026-08-05-mycli-node-runtime-m7-extensions-management-design.md`

## File Map

The implementation keeps each concern in a focused unit:

- `packages/core/src/types.ts`: provider ids/protocols, durable context, replay state, and events.
- `packages/core/src/extensions.ts`: neutral hook, extension diagnostic, and child-task value types.
- `packages/providers/src/anthropic-provider.ts`: Messages serialization and stream normalization.
- `packages/providers/src/provider-registry.ts`: protocol-neutral provider construction.
- `packages/integrations/src/foundation/`: ids, diagnostics, lifecycle, and registrations.
- `packages/integrations/src/skills/`: discovery, catalog, stable tool, and instruction artifacts.
- `packages/integrations/src/mcp/`: config, SDK lifecycle, transports, tools/resources, management.
- `packages/integrations/src/hooks/`: config, allowlist, command runner, ordering, management.
- `packages/integrations/src/plugins/`: v2 manifest/discovery, host, worker, commands, management.
- `packages/integrations/src/subagents/`: profiles, task state, controller, tools, management.
- `packages/contracts/schemas/plugin-v2-*.schema.json`: untrusted plugin boundary contracts.
- `packages/config/src/auth-store.ts`: atomic credential writes in the existing file format.
- `packages/config/src/user-config-writer.ts`: compatible atomic setup configuration writes.
- `packages/runtime/src/hook-coordinator.ts`: exact hook-point sequencing and failure policy.
- `packages/runtime/src/context-item-coordinator.ts`: atomic durable skill instruction injection.
- `packages/storage/src/subagent-task-store.ts`: additive durable child-task records.
- `apps/mycli/src/node-runtime/integration-composition.ts`: extension construction and shutdown.
- `apps/mycli/src/management/`: utility command parsing, services, renderers, setup, and doctor.
- `apps/mycli/src/cli.ts`: route utility commands before TTY/provider startup.
- `apps/mycli/src/node-runtime/node-gateway.ts`: extension/resource/command/subagent RPC projection.
- `scripts/smoke_node_m7_extensions.mjs`: structural live/local M7 smoke with no secret output.

Existing generated contract files are regenerated by `npm run contracts:generate`; never edit them
by hand. At every commit, leave unrelated dirty files unstaged.
