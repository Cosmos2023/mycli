# mycli Daily General-Agent Eval Scoring Rubric

## 1. 总分结构

建议总分为 `100` 分。

- `任务完成度`：30 分
- `正确性与可核验性`：20 分
- `记忆与跨轮延续`：15 分
- `工具选择与调用质量`：15 分
- `上下文管理`：10 分
- `语义理解与澄清`：5 分
- `协作体验`：5 分

## 2. 各维度说明

### 2.1 任务完成度

检查点：

- 是否真正完成用户目标
- 是否有可直接使用的交付物
- 是否遗漏关键要求

### 2.2 正确性与可核验性

检查点：

- 事实、数字、引用是否正确
- 修改类任务是否有实际验证
- 结论是否有证据支撑

### 2.3 记忆与跨轮延续

检查点：

- 是否记住前文约束
- 是否记住角色偏好、禁用项和最新限制
- 是否能在被打断后恢复主任务

### 2.4 工具选择与调用质量

检查点：

- 该用工具时是否用了工具
- 不该用时是否克制
- 是否有重复、低价值或错误方向的调用
- 是否正确吸收工具结果

### 2.5 上下文管理

检查点：

- 是否区分主任务与插入任务
- 是否及时吸收新约束
- 是否能稳定管理多轮信息

### 2.6 语义理解与澄清

检查点：

- 是否理解真正意图
- 是否在必要时做最小澄清
- 是否避免被字面措辞误导

### 2.7 协作体验

检查点：

- 表达是否清晰
- 是否区分事实、推测和建议
- 是否像一个可靠同事而不是一台只会输出的机器

## 3. 评级区间

- `90-100`
  - 接近可投入真实日常工作的通用个人助理 agent
- `75-89`
  - 已具备较强实用价值，但仍需要用户复核关键结果
- `60-74`
  - 可完成部分任务，但跨轮稳定性和工具纪律不足
- `<60`
  - 仍偏局部能力工具，尚未形成稳定的通用 agent 行为

## 4. 判分方式建议

建议采用双层判分：

1. 确定性检查
   - 文件 diff
   - 数值结果
   - 测试执行结果
   - 命中词与禁用词检查
2. rubric 评分
   - 多轮记忆质量
   - 工具纪律
   - 协作体验
   - 上下文管理

## 5. 评测记录建议

每次执行建议保留：

- 用户多轮输入
- agent 多轮回复
- 工具调用序列
- 最终产物
- 判分记录
- 失败原因摘要
