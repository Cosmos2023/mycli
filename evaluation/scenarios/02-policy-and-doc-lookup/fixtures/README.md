# 场景 02 Fixtures

## 建议文件

- `expense-policy.md`
- `travel-policy.md`
- `meeting-notes.md`

- `hidden-answer.md`

## 素材约束

- `travel-policy` 与 `faq` 至少应存在一个轻微冲突或表述差异
- 至少保留一个“文档中没有明确说明”的问题，专门测试克制
- 文件层次要清晰，便于检测引用是否准确
